# SQL_CURD

This repository contains **SQL Data Manager** — a modular, metadata-driven
Create/Read/Update/Delete module for Microsoft SQL Server, built with
React 19 + TypeScript + Vite on the frontend and ASP.NET Core (.NET 10) on the
backend.

The full application lives in [`SqlDataManager/`](SqlDataManager/). See
[`SqlDataManager/README.md`](SqlDataManager/README.md) for setup, run and
testing instructions.
